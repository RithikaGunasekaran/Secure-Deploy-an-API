# Secure-Deploy-an-API
Build and deploy a simple REST API application (e.g., Login API ) by implementing security, testing, containerization, and CI/CD concepts.
1. Activate env
2. python -m pytest
3. uvicorn app.main:app --host 0.0.0.0 --port 8000
4. Open http://localhost:8000/docs in browser to see endpoints
